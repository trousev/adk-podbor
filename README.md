# Подбор средств АДК

Статический опросник для первичного подбора средств альтернативной и дополнительной
коммуникации (АДК) у взрослых людей с РАС, проживающих в стационарных организациях
социального обслуживания.

Перенесён из Claude Artifact, чтобы не зависеть от доступа к аккаунту Claude.
Backend не нужен: всё работает в браузере, ответы хранятся локально (localStorage),
итог можно скопировать или отправить.

Живая версия: https://trousev.github.io/adk-podbor/
